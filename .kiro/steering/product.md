# StudySpec 产品导向

准备日期：2026-11-09。

StudySpec 是给独自学习的成年学生用的本地优先规划起步模板。它帮助把作业和复习排进有限的每日时间，并且在排不下的时候把剩余工作留在明处。

## 谁在用

- 使用者是独自准备作业和考试的成年学生。
- 当前阶段不收集姓名、邮箱、学校或账号。这些身份信息都还没有确定，文档和界面里不要编造。

## 产品形态

Skeleton Crew 的目标形态是：

- 一个可复用模板：`template/`，提供共享类型、校验、确定性排期和示例数据。
- 两个互相独立的应用：
  - `app-homework/`：作业救援。按课程、作业和截止日期拆工作块。
  - `app-exam-review/`：复习计划。按科目、主题和考试日期排复习。

两个应用读取同一份文档结构。同一份合法 JSON 可以被同一个解析器接受，并得到同一个排期结果。

## 必须遵守的行为

- 排期只由文档内容决定。不读取当前时钟，不依赖时区，不使用随机数。
- 每日容量或截止日期导致排不下时，剩余分钟进入「未排入」。系统不得悄悄丢掉事项。
- 示例数据必须自带标记，界面要把它和使用者自己的计划区分开。
- 导入的 JSON 先校验再使用。校验失败时保留错误说明，不把坏数据写进计划。
- 计划锚点日期写在数据里。界面按 `YYYY-MM-DD` 原样显示，不用本地时区换算日期。

## 明确不做

- 不做后端、账号、协作同步、原生 App 和分析埋点。
- 不调用生成式模型，不接付费 API，界面不声称结果来自人工智能。
- 现在不部署。GitHub Pages 只是以后可能的静态托管方式，当前没有授权部署。
- 当前仓库是私人准备草稿，不是公开 GitHub 仓库，也不是比赛的最终提交。

## 阶段边界

阶段 1 只交付规格、共享核心的最小可用部分，以及两个能启动的中文界面壳。浏览器本地存储、文件导入导出界面、修改和删除、子任务拆分都还没有实现。规格可以先写这些未来行为，任务清单必须保持未勾选，直到真的做完。
