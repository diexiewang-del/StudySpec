# StudySpec

StudySpec 是一个本地优先、结果可重复的学生规划起步模板。阶段 1 只准备规格和能运行的骨架，不是完整产品，也不是比赛的最终提交。

当前仓库是私人、未发布的准备草稿。比赛以后要求公开 GitHub 仓库；这份草稿本身不符合那条要求。这里没有创建公开仓库，没有部署网站，也没有提交任何报名表。

## 两个应用，一个核心

| 目录 | 是什么 |
| --- | --- |
| `template/` | 共享核心 `@studyspec/core`：类型、JSON 校验、规范序列化、确定性排期、示例数据 |
| `app-homework/` | 作业救援。按课程和截止日期看作业能不能排进每天的容量 |
| `app-exam-review/` | 复习计划。按科目、主题和考试日期排复习 |

两个应用不共用界面代码。它们都调用同一个核心，并使用同一种 `1.0.0` 文档。排不进容量的分钟会出现在「未排入」，不会被悄悄丢掉。

示例数据写明了自己是示例。锚点日期 `2026-11-09` 写在 JSON 里，程序不读取电脑时钟。

## 现在能用，以及还没做

已经接上：

- 示例 JSON 的校验、规范序列化和确定性排期
- 两个中文页面：示例横幅、未排入列表、只存在于本次打开页面里的添加表单
- 根目录的测试、类型检查和构建

还没有做：

- 浏览器本地存储。接口会明确返回「尚未实现」
- JSON 文件的导入导出按钮。解析和序列化函数已经有了，界面没有
- 修改、删除、调整每日容量、把一条作业拆成多个子任务
- 部署。GitHub Pages 只是以后可能的静态托管，现在没有授权

更完整的边界在 `.kiro/specs/student-planner/`。未完成的任务在 `tasks.md` 里保持未勾选。

## 环境

需要 Node.js 22.18 或更新版本。测试直接运行 TypeScript，不另装测试框架。本机核对时使用的是仓库锁文件里的依赖。

## 命令

```bash
npm install
npm test
npm run typecheck
npm run build
```

本地查看：

```bash
npm run dev:homework
npm run dev:exam
```

作业救援是 <http://127.0.0.1:43123>，复习计划是 <http://127.0.0.1:43124>。构建之后也可以用 `npm run preview:homework` 和 `npm run preview:exam`。验收不依赖开发服务器一直开着。

## 确定性

排期只看文档里的窗口、每日分钟、不可用日期、截止日期、优先级和标识。不使用当前时间、时区偏移或随机数。日期按 `YYYY-MM-DD` 原样显示。

同一份合法 JSON，两次解析和两次排期的结果相同。作业文档和复习文档的差别是 `kind` 以及课程或主题字段；解析器是同一个。
